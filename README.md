# 知识图谱探索器 · 《人类简史》

一个 **AI 辅助生成的交互式知识图谱小工具**：以尤瓦尔·赫拉利《人类简史》的核心概念为素材，把书里抽象的思想关系可视化成一个可探索的「深色知识宇宙」。

项目采用纯前端实现，**零依赖、离线可用**，把一张静态关系图升级为具备「搜索 → 图谱 → 详情 → AI 向导 → 分享」完整交互链的知识探索工作台。

## 在线体验

本地预览：在项目根目录启动静态服务后访问根路径即可。

```bash
python -m http.server 8000
# 访问 http://localhost:8000/
```

## 功能特性

- **力导向知识图谱**：自研轻量物理引擎（斥力 + 弹簧 + 中心约束），无第三方依赖；载入后收敛一次即冻结布局。
- **层级化节点**：按图结构自动识别枢纽，节点分 `lv0~lv3` 四档大小，主次分明。
- **中文搜索（标签加权）**：顶部搜索 + 全屏 **Ctrl+K / /** 命令面板；标签命中的概念优先，描述/追问全文降权召回；带「最近探索 / 推荐」。
- **知识详情侧栏**：点击节点弹出分类、层级、简介、关联追问（可展开）、相关概念可点、一键展开知识链。
- **AI 知识向导**：根据当前探索节点动态给出追问建议；基于预设知识作答，并诚实标注为「原型提示 · 非实时模型」。
- **交互与导航**：平移（拖拽 + 触屏）、缩放（滚轮 + 移动端双指）、双击深入、节点 Hover 知识聚焦、有关联连线发光。
- **类型过滤器**：图例即过滤器，点击隐藏/显示某一类节点，并带计数与重置。
- **分享截图**：一键导出当前图谱为 PNG（纯 SVG 生成，规避浏览器 canvas 污染限制）。
- **沉浸视觉**：深色环境光 + 微网格 + 呼吸星尘背景，毛玻璃面板。

## 数据内容

`data/humans.json` 预置了：

- **14 个概念节点**（认知革命、农业革命、金钱、帝国、宗教、资本主义、科学革命、自由人文主义、人工智能与未来等）
- **21 条带关系标签的边**（如「资本驱动工业」「催生语言与想象」）
- **21 条关联追问与预设答案**
- **5 大可看作色分类**：革命/演进、核心概念、制度/秩序、主题思考、未来与AI

数据为 JSON 结构，添加新概念时只需补充 `nodes`/`edges` 数组即可。

## 项目结构

```
├─ index.html        页面骨架（导航 / 图谱画布 / 详情侧栏 / AI 向导 / 命令面板）
├─ css/style.css     深色知识宇宙视觉系统（玻璃拟态 / 星尘 / 层级节点）
├─ js/app.js         力导向引擎、搜索、聚焦高亮、缩放、分享、AI 向导等全部逻辑
└─ data/humans.json  《人类简史》概念 / 关系 / 追问数据
```

## 技术说明

- 纯原生 `HTML + CSS + JavaScript`（ES5 风格 IIFE，广泛兼容），无构建步骤、无外部依赖。
- 物理引擎为 `O(n²)` 力计算；当前 14 节点无压力，若扩展至上百节点建议引入网格加速或拆到 Web Worker。
- 截图分享采用「按数据重建纯 SVG → 画到 canvas 导出 PNG」方案，规避 foreignObject 触发的 canvas 污染。
