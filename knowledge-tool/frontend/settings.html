LLM API（AI 方向采集）

用于「AI 方向采集」：只需给方向，AI 自动按知识库规范整理入库。支持三协议：OpenAI Chat / OpenAI Responses / Anthropic，可自动识别。

AI 提示词模板

内置模板：资讯速览 / 深度分析（含个人思考）/ 教程讲解。可新增或编辑自定义模板，供 AI 采集页选择。模板正文为系统提示词（要求输出 JSON 时的字段结构由你定义，采集器会用 title/summary/topic/tags/bullet_points/related_entities/related_concepts/thoughts）。

定时调度

配置 cron 定时任务，到点自动执行采集/整理/日报（后台调度器，随服务启动运行）。cron 5 段：分 时 日 月 周，如 0 8 * * *=每天 08:00。

关于正式版

正式完整版 =「知识库工作流工具」（Python + FastAPI + 原生前端 + 文件数据层，Linux/Docker 部署）。 「知识图谱探索器」是它的前端「知识结构」展示视图。本工具一期为纯手动可控，二期预留定时调度与 AI 增强。
