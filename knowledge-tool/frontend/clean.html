整理

去重、打标签、抽关键词、归类。运行期不调用 AI，纯本地规则，离线可用。

批量整理

对全库运行整理器：抽取关键词、按规则打标签、生成一句话摘要，并将状态置为 clean。纯本地规则，离线可用。

AI 增强整理 需 LLM

对全库用 LLM 再提炼一遍：优化标题/摘要、补充标签，并识别实体/概念写入双链、建骨架页——弥补规则整理对「任意正文实体识别」的短板（尤其链接/粘贴来源）。未配置 LLM Key 时此按钮不可用，规则整理不受影响。

实体/概念聚合补全 需 LLM

对被 2 篇以上来源引用的实体/概念页，用 LLM 把各来源信息综合成「概览」写入骨架页——解决图谱节点「有的丰富有的单薄」。单引用的新节点会自动跳过。
